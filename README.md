# Safeway Limousine (سيف واي ليموزين)

> الموقع الرسمي لشركة **سيف واي ليموزين** (Safeway Travels & Limousine Services) ببورسعيد وجميع محافظات جمهورية مصر العربية.

![Safeway Limousine](./images/safeway-logo.jpg)

---

## 🌟 مميزات المشروع (Key Features)

- **تصميم فخم (Ultra-Luxury Dark Theme):** مبني بأحدث معايير الويب وتنسيقات Tailwind CSS وخطوط Google Fonts (Cairo & Montserrat).
- **دعم ثنائي اللغة (Bilingual i18n):** تبديل سلس وسريع بين العربية (RTL) والإنجليزية (LTR) مع قلب كامل للواجهات وتخزين التفضيل محلياً.
- **محرك حجز ذكي (Smart Booking Engine):** نموذج حجز تفاعلي مع مسارات سريعة وتوجيه فوري لرسائل WhatsApp منسقة إلى رقم خدمة العملاء: `+201229242094`.
- **أزرار تواصل عائمة (Floating Actions):** زر واتساب نابض وزر اتصال هاتفي مباشر وزر العودة للأعلى.
- **قسم سيارات زفاف العرايس (Wedding Limousines):** استعراض سيارات الزفاف الفاخرة (مرسيدس برابوس، مرسيدس AMG، بيجو 508) مع نافذة تكبير Lightbox.
- **أسطول سيارات حديث 2020-2024 (Fleet Showcase):** فلاتر تصنيف تفاعلية لسيارات السيدان، الـ SUV، الزفاف، وفانات الـ VIP المجهزة.
- **خريطة موقع ليلية تفاعلية (Dark Google Maps):** متمركزة على بورسعيد، مصر.
- **إبراز المقر الحقيقي للشركة:** واجهة الفرع الرسمي ببورسعيد وقائمة المزايا المعتمدة.
